# Cuentas Claras (prototipo)

Prototipo web de una sola página. Lee resúmenes de tarjeta (Galicia Visa/Mastercard, Mercado Pago) en el navegador, sin IA y sin subir nada. Los datos se guardan en el navegador de cada dispositivo.


## App real

Está en construcción: base de datos en Supabase (`supabase/`), app en Flutter (`app/`). Ver [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md).
